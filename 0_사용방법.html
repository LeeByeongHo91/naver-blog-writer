블로그 글 생성기 사용방법

구글 드라이브에 사진을 올려 두면, AI가 사진을 보고 블로그 주인의 말투로 글을 써서 네이버 블로그에 임시저장까지 해 주는 프로그램입니다. 발행은 글을 확인한 뒤 직접 누릅니다.

한눈에 보기

처음 한 번만 1~4번을 하면 되고, 그다음부터는 5번과 6번만 반복하면 됩니다.

  • 1. 압축 풀기
  • 2. API 키 받기
  • 3. 설치
  • 4. 처음 설정
  • 5. 사진 올리기
  • 6. 글 만들기

준비물

  • 윈도우 PC (윈도우 10 또는 11)
  • 네이버 아이디 (블로그를 쓰는 계정)
  • 구글 계정 (사진을 올려 둘 구글 드라이브용)
  • 해외 결제가 되는 카드 (VISA, Master 등). AI 사용료를 충전할 때 씁니다.
비용은 얼마나 드나요? 글 하나에 약 200원입니다(사진이 많으면 조금 더). 처음에 5달러(약 7천 원)를 충전하면 글 30편 안팎을 쓸 수 있습니다. 매달 나가는 돈은 없고, 충전한 만큼만 씁니다.

1압축 풀기 1분

  1. 받은 블로그글생성기 zip 파일을 바탕 화면에 둡니다.
  2. 파일을 마우스 오른쪽 버튼으로 누르고 "압축 풀기" (또는 "모두 압축 풀기")를 누릅니다.
  3. 블로그글생성기 폴더가 생깁니다. 앞으로는 이 폴더를 열어서 씁니다.
꼭 압축을 푼 뒤에 쓰세요. zip 파일을 더블클릭해서 그 안에서 바로 실행하면 작동하지 않습니다.

2API 키 받기 10분

API 키는 AI를 쓸 수 있게 해 주는 나만의 비밀번호입니다. sk-ant-로 시작하는 긴 글자입니다. 처음 한 번만 받으면 됩니다.

사이트가 영어로 되어 있습니다. 크롬이나 엣지에서 화면 빈 곳을 마우스 오른쪽 버튼으로 누르고 "한국어로 번역"을 누르면 한글로 볼 수 있습니다. 아래에는 영어 버튼 이름을 그대로 적었습니다.

2-1. 가입하기

  1. 인터넷 주소창에 platform.claude.com 을 입력해 들어갑니다.
  2. "Continue with Google"을 눌러 구글 계정으로 가입하는 것이 가장 쉽습니다. (이메일 주소를 직접 넣어도 됩니다. 그 경우 메일로 온 링크를 눌러야 합니다.)
  3. 이름이나 사용 목적을 물으면 편하게 적습니다. 회사 이름(Organization)을 물으면 가게 이름이나 본인 이름을 적으면 됩니다.

2-2. 사용료 충전하기

  1. 화면 왼쪽 메뉴에서 "Settings" → "Billing"(결제)을 누릅니다. 메뉴가 안 보이면 왼쪽 위 메뉴 버튼이나 왼쪽 아래 본인 이름을 눌러 찾습니다.
  2. "Buy credits" 또는 "Add funds" 버튼을 누릅니다.
  3. 카드 번호, 유효기간, 뒷면 3자리 숫자를 넣고, 금액은 5(달러)로 합니다.
  4. 결제를 마치면 화면에 잔액(Credit balance)이 5달러로 보입니다.
자동 충전(Auto reload)을 켜겠냐고 물으면 끄는 것을 권합니다. 꺼 두면 충전한 금액 이상은 절대 빠져나가지 않습니다.

2-3. 키 만들기

  1. 왼쪽 메뉴에서 "API Keys"를 누릅니다.
  2. "Create Key" 버튼을 누릅니다.
  3. 이름(Name)을 적는 칸에는 blog처럼 아무 이름이나 적고 "Create" 또는 "Add"를 누릅니다.
  4. sk-ant-로 시작하는 긴 글자가 나옵니다. 옆의 "Copy"(복사) 버튼을 누릅니다.
  5. 바로 메모장을 열어 붙여넣기(Ctrl+V) 해 둡니다. 4번 설정에서 씁니다.
키는 만들 때 딱 한 번만 보입니다. 창을 닫으면 다시 볼 수 없으니 꼭 복사해 두세요. 잃어버렸다면 같은 방법으로 새로 만들면 됩니다.
키는 남에게 보여 주지도, 보내지도 마세요. 다른 사람이 알면 내 충전금을 쓸 수 있습니다. 이 프로그램을 받은 사람도 각자 자기 키를 만들어 넣어야 합니다.

3설치하기 10분

  1. 블로그글생성기 폴더를 열고 1_설치 를 더블클릭합니다.
  2. 파란 창에 "Windows의 PC 보호"라고 나오면 "추가 정보"를 누른 뒤 "실행"을 누릅니다.
  3. 검은 창이 뜨고 필요한 프로그램을 알아서 설치합니다. 중간에 "이 앱이 디바이스를 변경하도록 허용하시겠어요?"라고 물으면 "예"를 누릅니다. (두세 번 나올 수 있습니다.)
  4. "폰으로 찍은 사진을 구글 드라이브에 올려서 쓰시겠어요?"라고 물으면, 폰 사진을 쓸 거면 Y, PC에 있는 사진만 쓸 거면 N을 누르고 Enter를 누릅니다.
  5. Y를 눌렀으면 구글 드라이브 창이 뜹니다. 사진을 올릴 구글 계정으로 로그인하면 내 PC에 "Google Drive (G:)" 드라이브가 생깁니다. 로그인을 마쳤으면 검은 창으로 돌아와 Enter 키를 누릅니다.
  6. 바탕 화면에 "블로그 글 생성기" 아이콘 이 생깁니다. 다음부터는 이 아이콘만 더블클릭하면 됩니다.
  7. 이어서 블로그 글 생성기 창이 열리고 "처음 설정" 안내가 나옵니다. 바로 4번으로 넘어갑니다.
검은 창에 "PC를 다시 켠 뒤 '1_설치'를 한 번 더 실행해 주세요"라고 나오면, 그대로 PC를 껐다 켜고 1_설치 를 다시 더블클릭하면 됩니다.

4처음 설정 5분

처음 실행하면 설정을 한 단계씩 물어봅니다. 화면에 빨간 표시가 된 곳을 순서대로 누르면 됩니다. 각 단계에서 맨 아래 초록색 "다음 →"을 누르면 다음 단계로 넘어갑니다.

1단계. API 키

2번에서 메모장에 붙여 둔 sk-ant- 키를 복사해서 붙여넣고 "연결 확인"을 누릅니다. "✅ 연결됐습니다"가 초록색으로 나오면 성공입니다.

  • "API 키가 올바르지 않습니다": 키를 복사할 때 앞뒤가 잘렸을 수 있습니다. 다시 복사해서 붙여넣습니다.
  • "충전된 돈(크레딧)이 없습니다": 2-2번처럼 충전한 뒤 다시 누릅니다.

2단계. 블로그 아이디

네이버 로그인할 때 쓰는 아이디를 적고 "블로그 확인"을 누릅니다. 내 블로그 이름이 나오면 맞게 적은 것입니다. 비밀번호는 적지 않습니다.

아이디가 헷갈리면 휴대폰이나 PC에서 내 블로그를 열고 주소창의 주소를 통째로 복사해서 붙여넣어도 됩니다. 아이디만 알아서 골라 냅니다.

3단계. 사진 폴더

"폴더 고르기" → "구글 드라이브 (내 드라이브)" → 사진 폴더를 눌러 들어간 뒤 → "이 폴더 선택"을 누릅니다.

사진 폴더를 아직 안 만들었으면, 아래 5번(사진 올리기)을 먼저 하고 돌아와도 됩니다. 프로그램 창은 그대로 두세요.

4단계. 블로그 소개

어떤 블로그인지, 누가 읽는지 한두 줄로 적습니다. AI가 글의 관점과 말을 거는 대상을 여기에 맞춥니다.

예: 대구에서 태권도장을 운영하는 관장의 블로그. 읽는 사람은 주로 학부모님. / 수원에서 인테리어 업체를 하는 사장의 블로그. 읽는 사람은 집 수리를 알아보는 분들.

5단계. 내 글 예시 (말투)

"📥 내 블로그에서 가져오기"를 누르면 내 블로그의 최근 글 목록이 나옵니다. 내 말투가 잘 드러난 글 2~3편에 체크하고 "선택한 글 넣기"를 누릅니다. AI가 이 글들을 보고 말투, 이모지, 인사말을 따라 씁니다.

아직 블로그에 글이 없으면 건너뛰어도 됩니다. 마지막으로 "다 됐어요! 글 만들러 가기 →"를 누르면 설정이 끝나고 글 만들기 화면으로 넘어갑니다.

나중에 설정을 바꾸려면

프로그램 창 위쪽의 "설정" 탭을 누르면 모든 설정이 한 화면에 나옵니다. 고친 뒤 맨 아래 "설정 저장"을 누릅니다. 처음 설정에 없던 것들은 이런 것이 있습니다. 필요할 때만 쓰면 됩니다.

매번 들어가야 할 내용가게 이름, 위치, 연락처처럼 글마다 넣고 싶은 정보입니다.
말투, 글 길이'내 글 예시'가 없을 때만 씁니다. 예시가 있으면 예시를 따릅니다.
항상 붙일 해시태그글마다 꼭 넣을 해시태그입니다. 나머지는 AI가 글에 맞게 붙입니다.
⚙ 고급 설정 — 글 맨 위에 항상 넣을 이미지가게·도장 로고나 인사 배너처럼 모든 글의 맨 위(제목 바로 아래)에 넣을 이미지입니다. "+ 이미지 추가"로 넣고 ◀▶로 순서를 바꿉니다. 네이버는 글의 첫 사진을 대표 이미지(검색 썸네일)로 쓰기 때문에, 글마다 대표 이미지를 바꾸고 싶으면 네이버 글쓰기 화면에서 다른 사진의 '대표'를 눌러 주세요.
⚙ 고급 설정 — 글 끝에 항상 붙일 내용가게 소개, 네이버 지도, 톡톡, 유튜브, 인스타그램처럼 매번 글 끝에 똑같이 들어가는 부분입니다. 지도: 가게 이름, 도로명 주소 줄은 지도로, https://로 시작하는 주소만 있는 줄은 링크 카드(배너)로 들어갑니다. 유튜브는 영상이 아니라 채널 주소를 적어야 배너 모양으로 나옵니다.
⚙ 고급 설정 — 네이버 '내 템플릿'네이버 글쓰기의 템플릿 → 내 템플릿에 저장해 둔 글 끝이 있으면 그 이름을 그대로 적습니다. 템플릿 모양 그대로 글 맨 아래(해시태그 바로 앞)에 들어갑니다.
⚙ 고급 설정 — 항상 지킬 요청단어 바꾸기(예: 선생님 → 사범님), 반복해서 넣을 말(예: 동네 이름 + 가게 이름 2~3번), 그 밖에 매번 하는 부탁을 적어 두면 글마다 지킵니다.

처음 설정 안내를 다시 보고 싶으면 설정 탭 맨 위 "처음 설정 도우미 다시 하기"를 누릅니다.

5사진·동영상 올리기

폰으로 찍은 사진 (구글 드라이브)

글에 쓸 사진을 구글 드라이브의 사진 폴더에 넣어 둡니다. 폰에서 올리면 PC에 자동으로 나타납니다.

  1. 폰에 "Google Drive"(구글 드라이브) 앱을 설치하고, PC와 같은 구글 계정으로 로그인합니다.
  2. 앱에서 + 버튼 → "폴더"로 네이버블로그 같은 폴더를 하나 만듭니다. (처음 한 번만)
  3. 그 폴더에 들어가 + 버튼 → "업로드"로 글에 쓸 사진과 동영상을 고릅니다.
  • 한 번 글에 쓴 사진은 기억해 두고 다음에는 목록에서 감춥니다. 드라이브의 사진은 지워지지 않습니다. 이미 쓴 사진을 다시 쓰고 싶으면 글 만들기 화면에서 "이미 글에 쓴 사진도 보기"를 켜면 됩니다.
  • 동영상도 같은 폴더에 넣으면 글 사이에 함께 들어갑니다.
아이폰 사진(HEIC)도 그대로 쓸 수 있습니다. 프로그램이 알아서 JPG로 바꿔서 넣습니다. 원래 사진은 그대로 둡니다.

PC에 있는 사진

  • 글 만들기 화면 '2. 사진 고르기' 칸에 사진 파일을 끌어다 놓거나, "📂 PC에서 사진 추가"를 눌러 고르면 됩니다. 사진 폴더에 복사되고 바로 골라집니다.
  • 구글 드라이브를 안 쓰면 설정의 사진 폴더를 "📷 내 PC 사진 폴더"처럼 PC 폴더로 골라 두면 됩니다.

6글 만들기 3~5분

  1. 바탕 화면의 "블로그 글 생성기" 아이콘 을 더블클릭하면 블로그 글 생성기 창이 열립니다. (작업 표시줄에 검은 창이 하나 같이 생기는데 그대로 두세요. 프로그램 창을 닫으면 같이 닫힙니다.)
  2. 1. 글 형식: 어떤 글을 쓸지 먼저 고릅니다. 고른 형식은 다음에도 기억합니다. 말투는 어느 형식이든 '내 글 예시'를 따라 씁니다.
    • ① 일상 데일리: 사진을 하나씩 보여 주며 가게·도장·나의 하루를 가볍게 씁니다.
    • ② 정보 칼럼: 정보, 노하우, 내 생각처럼 주제 하나를 깊이 있게 씁니다. 사진은 글 내용에 맞는 자리에 AI가 넣기 때문에 순서가 바뀔 수 있습니다. 수치, 가격, 일정 같은 구체적인 사실은 '하고 싶은 이야기' 칸에 적어 준 것만 씁니다.
    • ③ 브이로그·후기: 행사, 대회, 여행을 다녀온 하루를 시간 순서대로 씁니다. 행사 이름, 날짜, 결과는 꼭 적어 주세요.
  3. 2. 사진 고르기: 드라이브에 올린 사진이 작은 그림으로 나옵니다. 글에 넣을 사진을 누르면 번호가 붙고, 다시 누르면 빠집니다.
  4. 3. 순서와 사진 메모: 고른 사진이 위에서부터 글에 들어갈 순서대로 놓입니다.
    • 왼쪽 번호를 잡고 끌어서 놓거나, 오른쪽 ▲▼ 버튼으로 순서를 바꿉니다. 블로그에 이 순서 그대로 들어갑니다.
    • 사진 옆 메모 칸에 그 사진에서 하고 싶은 말을 적습니다. 예: 오늘 처음 선보인 메뉴, 손님 반응이 좋았음. AI가 그 내용과 느낌을 살려서 그 사진 부분을 씁니다. 비워 둬도 됩니다.
  5. 4. 이번 글: 세 칸을 채웁니다. 모두 비워 둬도 됩니다.
    • 주제: 무슨 글인지 한 줄로. 비워 두면 AI가 사진을 보고 정합니다.
    • 강조하고 싶은 점: 읽는 사람에게 꼭 전하고 싶은 메시지입니다. 이걸 중심으로 글을 풀어 갑니다.
    • 이번 글의 느낌, 하고 싶은 이야기: 글 전체의 분위기와, 날짜·인원·행사 결과처럼 사진만 봐서는 알 수 없는 사실을 적습니다. AI는 모르는 사실을 지어내지 않도록 되어 있어서, 여기와 사진 메모에 적어 준 것만 글에 들어갑니다.
  6. 초록색 "블로그 글 만들고 임시저장하기"를 누릅니다. 아래에 진행 상황이 나옵니다. AI가 글을 쓰는 데 보통 1~3분 걸립니다.
  7. 글 확인: 버튼 위의 "✍ 네이버에 넣기 전에 AI가 쓴 글을 먼저 보고 고치기"가 켜져 있으면, AI가 다 쓴 글이 먼저 화면에 나옵니다.
    • 제목, 문단, 사진 설명, 해시태그를 바로 고칠 수 있습니다.
    • 마음에 안 들면 "🔄 다시 써 줘"를 누릅니다. 옆 칸에 더 짧게, 인사말은 빼고처럼 바랄 점을 적으면 그대로 고쳐 씁니다. (다시 쓸 때마다 사용료가 한 번 더 듭니다)
    • 괜찮으면 "✅ 이대로 네이버에 넣기"를 누릅니다.
    • 확인 없이 바로 네이버에 넣고 싶으면 이 칸의 체크를 끄면 됩니다. 다음에도 기억합니다.
  8. 얼굴 모자이크: 만들기 버튼 위의 "🙈 사진 속 얼굴 모자이크"를 켜면 사진 속 얼굴을 자동으로 찾아 가립니다 (블로그·인스타·쇼츠 사진 모두). 얼굴 찾기는 이 PC 안에서만 하고 사진을 어디에도 보내지 않습니다.
    • '글 확인'에 "🙈 얼굴 모자이크 확인"이 나옵니다. 흐리게 보이는 네모가 가릴 곳입니다.
    • 가리지 않을 얼굴(예: 관장님, 사장님 본인)은 그 네모를 누르면 점선으로 바뀌고 가리지 않습니다. 다시 누르면 다시 가립니다.
    • 못 찾은 얼굴이 있으면 사진에서 그 얼굴을 누르세요. 그 자리에 네모가 생깁니다. 옆을 보거나 작게 찍힌 얼굴은 못 찾을 때가 있으니 꼭 한 번 훑어봐 주세요.
    • 동영상 속 얼굴은 가리지 못합니다.
  9. 인스타·쇼츠: "📱 인스타그램 사진·글과 쇼츠 영상도 같이 만들기"를 켜 두면, 같은 사진으로 인스타그램 글과 쇼츠 자막도 같이 씁니다 (추가 사용료 약 10원). '글 확인' 아래쪽 "📱 인스타그램·쇼츠 글"에서 고칠 수 있습니다. 네이버 입력이 끝나면 사진과 영상 파일을 만듭니다 (30초~1분). 올리는 방법은 아래 "인스타그램·유튜브 쇼츠 올리기"를 보세요.
  10. 처음 한 번만 브라우저(엣지) 창에 네이버 로그인 화면이 뜹니다. 직접 로그인하고, "로그인 상태 유지"에 체크하면 다음부터는 묻지 않습니다.
  11. 네이버 글쓰기 화면에 제목, 글, 사진이 자동으로 입력됩니다. 끝날 때까지 그 창을 건드리지 말고 기다립니다.
  12. "다 됐습니다!"가 나오면 네이버 창에서 글을 읽어 보고, 고칠 곳을 고친 뒤 오른쪽 위 "발행"을 누릅니다. 다 봤으면 네이버 창을 닫습니다. 다음 글을 만들려면 네이버 창을 먼저 닫아야 합니다.
나중에 발행하려면 그냥 네이버 창을 닫으면 됩니다. 네이버 글쓰기 화면 오른쪽 위 "저장" 옆 숫자를 누르면 임시저장한 글을 다시 열 수 있습니다.
만든 글과 사용료는 위쪽 "지난 글" 탭에서 볼 수 있습니다. 지난 글을 눌러 다시 읽거나 "📋 글 복사"로 복사할 수 있고, 이번 달 AI 사용료(대략)도 나옵니다. 정확한 청구 금액은 platform.claude.com 의 Billing에서 확인합니다.
발행 전에 꼭 한 번 읽어 주세요. AI가 쓴 글이라 사실과 다른 내용이나 어색한 표현이 섞일 수 있습니다. 특히 사람 이름, 날짜, 가격, 행사 결과는 직접 확인해 주세요.

인스타그램·유튜브 쇼츠 올리기

글을 다 만들면 진행 상황 아래에 "📱 인스타·쇼츠 준비 완료"가 나옵니다. 만든 파일은 "📂 파일 폴더 열기"로 볼 수 있고, 나중에도 "지난 글" 탭에서 그 글을 누르면 아래에 다시 나옵니다.

  • 인스타_01.jpg ~ : 인스타그램 게시물용 세로 사진(4:5). 가로 사진은 잘리지 않게 흐린 배경 위에 올려 둡니다.
  • 인스타_글.txt : 인스타그램 본문과 해시태그
  • 쇼츠.mp4 : 사진이 천천히 넘어가는 세로 영상(9:16, 15~40초). 첫 화면에 제목, 사진마다 자막이 나옵니다.
  • 쇼츠_제목과_설명.txt : 유튜브에 올릴 때 쓸 제목과 설명

인스타그램

  1. "📋 인스타 글 복사"를 누른 뒤 "인스타그램 열기"를 누릅니다. 평소 쓰는 브라우저에 인스타그램이 열립니다 (처음엔 로그인).
  2. 왼쪽 "만들기" → "컴퓨터에서 선택" → 폴더의 인스타_01~ 사진을 한꺼번에 고릅니다 (Ctrl+A).
  3. 글 칸에 붙여넣기(Ctrl+V) 하고 "공유하기"를 누릅니다.

유튜브 쇼츠

  1. "📋 제목·설명 복사"를 누른 뒤 "유튜브 스튜디오 열기"를 누릅니다.
  2. 오른쪽 위 "만들기" → "동영상 업로드" → 폴더의 쇼츠.mp4를 고릅니다. 세로 영상이라 저절로 쇼츠가 됩니다.
  3. 제목·설명 칸에 붙여넣고 공개 범위를 고른 뒤 게시합니다.
같은 영상을 인스타그램 릴스로 올려도 됩니다.

배경 음악 넣기

설정 → ⚙ 고급 설정 → 9. 쇼츠 배경 음악에 무료 기본 음악 8곡(밝은 곡 5, 잔잔한 곡 3)이 들어 있습니다. ▶로 들어 보고 마음에 드는 곡에 체크하면 쇼츠 영상에 깔립니다. 여러 곡에 체크하면 영상마다 하나를 골라 쓰고, 끝은 서서히 작아집니다. 하나도 안 고르면 소리 없는 영상이 되고, 올릴 때 인스타그램·유튜브 안에서 음악을 골라도 됩니다.

기본 음악은 HoliznaCC0가 저작권을 포기하고(CC0) 공개한 곡이라 유튜브·인스타그램 어디에 올려도 되고, 출처를 적지 않아도 됩니다.

다른 곡을 쓰고 싶으면 아래 "+ 음악 추가"로 음악 파일(MP3 등)을 넣을 수 있습니다.

저작권에 주의하세요. 직접 넣는 곡은 마음대로 써도 되는 곡만 넣으세요. 가요·드라마 음악을 넣으면 영상이 막히거나 소리가 꺼질 수 있습니다. 유튜브 오디오 보관함 곡도 유튜브 밖(인스타그램 등)에서는 쓰지 못하는 곡이 많습니다.

지난 글로 다시 만들기

"지난 글" 탭에서 글을 누르면 아래에 "📱 인스타·쇼츠"가 나옵니다.

  • "🔄 다시 만들기": 음악을 새로 넣었거나 모자이크 설정을 바꿨을 때 지금 설정으로 다시 만듭니다. 글은 남아 있는 것을 써서 사용료가 들지 않습니다.
  • "📱 인스타·쇼츠 만들기": 인스타·쇼츠를 끄고 만든 글이나 예전 버전에서 만든 글도 만들 수 있습니다. 이때는 AI가 블로그 글과 사진을 보고 인스타·쇼츠 글만 새로 씁니다 (약 30원). 예전 글은 사진 폴더에서 같은 이름의 사진을 찾아 쓰므로, 그 사진을 지웠거나 옮겼으면 만들 수 없습니다.

말투를 더 비슷하게 만들려면

설정 → 5. 내 글 예시에 내가 직접 쓴 블로그 글을 넣어 두면, AI가 매번 그 글들을 보고 말투와 글 구성을 따라 합니다. 가장 쉬운 방법은 "📥 내 블로그에서 가져오기"를 눌러 글에 체크하는 것입니다(4번 5단계 그림 참고).

목록에 안 나오는 글(오래된 글 등)은 직접 붙여넣을 수 있습니다.

  1. 네이버 블로그에서 "이게 내 글 같다" 싶은 글을 엽니다.
  2. 글 화면을 한 번 누르고 Ctrl+A(전체 선택), Ctrl+C(복사)를 누릅니다. 메뉴 글자가 같이 복사돼도 프로그램이 알아서 걸러 냅니다.
  3. 설정의 예시 글 칸을 누르고 Ctrl+V로 붙여넣습니다. 칸이 모자라면 "+ 직접 붙여넣을 칸 추가"를 누릅니다. 메모장(.txt)에 모아 둔 글이 있으면 "txt 파일에서 불러오기"로 한 번에 넣을 수 있습니다.
  4. 맨 아래 "설정 저장"을 누릅니다.
  • 2~5편이 적당합니다. 많이 넣을수록 글 하나당 사용료가 조금씩 오릅니다.
  • 마음에 안 드는 예시는 "✕ 빼기"로 빼면 됩니다.
  • 예시 글은 사용자마다 따로 저장되고, 프로그램을 남에게 줄 때 같이 가지 않습니다.

여러 사람이 쓰려면

다른 사람에게 프로그램을 줄 때

  1. 블로그글생성기 폴더에서 4_다른 사람에게 줄 파일 만들기 를 더블클릭합니다.
  2. 바탕 화면에 블로그글생성기_나눠주기.zip 이 생깁니다. 이 파일을 카카오톡이나 메일로 보내면 됩니다.
  3. 받은 사람은 이 안내서의 1번(압축 풀기)부터 그대로 하면 됩니다. API 키, 네이버 아이디, 사진 폴더, 말투 예시는 받은 사람이 자기 것으로 넣습니다.
이 zip에는 내 API 키, 내 설정, 네이버 로그인, 말투 예시가 들어가지 않습니다. 모두 내 PC 안에만 저장되기 때문에 안심하고 보내도 됩니다. (폴더를 통째로 압축해서 보내지 말고 꼭 이 방법으로 만든 zip을 보내 주세요.)

한 PC에서 여러 블로그를 쓸 때

  1. 프로그램 창 맨 위 오른쪽 👤 칸을 누르고 "+ 새 사용자 추가..."를 고릅니다. (설정 탭 맨 위 '사용자'에서도 됩니다.)
  2. 이름을 적습니다. 지금 쓰는 API 키를 같이 쓸지 물으면, 사용료를 내가 내도 되면 확인, 그 사람이 자기 키를 넣을 거면 취소를 누릅니다.
  3. 새 사용자는 "처음 설정" 안내가 다시 나옵니다. 그 사람의 블로그 아이디, 사진 폴더, 말투 예시를 차례로 넣습니다.
  4. 처음 글을 만들 때 네이버 로그인 창이 뜨면 그 사람의 네이버 아이디로 로그인합니다. 로그인은 사용자마다 따로 기억합니다.

다음부터는 👤 칸에서 사용자만 바꾸면 그 사람의 설정과 네이버 계정으로 글을 만듭니다. 이미 쓴 사진 기록도 사용자마다 따로입니다.

문제가 생겼을 때

"설정이 아직 안 되어 있습니다"프로그램 창 위쪽 "설정" 탭에서 API 키, 블로그 아이디, 사진 폴더를 넣고 저장합니다.
"새로 올린 사진이 없습니다"폴더에 이미 글에 쓴 사진만 남아 있을 때 나옵니다. 같은 사진으로 다시 만들려면 "이미 글에 쓴 사진도 보기"를 켭니다. 새 글을 쓰려면 새 사진을 올리고 "새로고침"을 누릅니다.
"이 폴더에 사진이나 동영상이 없습니다"사진 폴더가 비어 있습니다. 구글 드라이브 폴더에 사진을 올린 뒤 "새로고침"을 누릅니다.
"앞에서 연 네이버 글쓰기 창이 아직 열려 있습니다"지난번 글의 네이버 창을 닫은 뒤 다시 누릅니다.
사진 그림이 안 나오고 파일 이름만 보여요구글 드라이브에서 사진을 내려받는 중이거나, 미리보기를 못 만드는 파일입니다. 잠시 뒤 "새로고침"을 누릅니다. 동영상은 형식에 따라 그림 대신 이름만 나올 수 있는데, 글에는 정상으로 들어갑니다.
"사진 폴더를 찾을 수 없습니다"구글 드라이브가 꺼져 있을 때 나옵니다. 시작 메뉴에서 "Google Drive"를 실행하고, 내 PC에 G: 드라이브가 보이는지 확인합니다.
"API 키가 올바르지 않습니다"키를 복사할 때 앞뒤가 잘렸을 수 있습니다. "설정" 탭에서 키를 다시 붙여넣습니다. 안 되면 2-3번대로 키를 새로 만듭니다.
"크레딧이 남아 있는지 확인해 주세요"충전금을 다 쓴 것입니다. platform.claude.com 의 Billing에서 2-2번처럼 다시 충전합니다.
"네이버에 입력하는 중 문제가 생겼습니다"만든 글은 없어지지 않습니다. 위쪽 "지난 글" 탭에서 그 글을 열어 "📋 글 복사"로 복사해 직접 붙여넣을 수 있습니다. 다시 실행하면 대부분 해결됩니다.
오류가 계속 나요오류가 나면 진행 상황 칸 아래 "📋 오류 내용 복사"를 누르고, 프로그램을 준 사람에게 카카오톡으로 붙여넣어 보내 주세요. 고쳐지면 새 버전 알림이 뜹니다.
"글쓰기 화면을 열지 못했습니다"설정의 블로그 아이디가 로그인한 네이버 아이디와 같은지 확인합니다.
바탕 화면 아이콘을 눌러도 창이 안 떠요작업 표시줄의 검은 창을 눌러 안내 문구를 확인합니다. 프로그램 폴더를 다른 곳으로 옮겼다면 옮긴 폴더에서 1_설치 를 한 번 더 실행하면 아이콘이 새로 만들어집니다. 그래도 안 되면 폴더 안의 3_블로그 글 올리기 를 더블클릭해도 같습니다.
"블로그를 찾지 못했습니다" / 내 블로그에서 가져오기에 글이 안 나와요블로그 아이디를 다시 확인합니다. 아직 글이 없는 블로그이거나 블로그 설정에서 RSS를 꺼 두었으면 확인이 안 되는데, 그래도 글쓰기는 됩니다. 말투 예시는 글을 직접 복사해서 붙여넣으면 됩니다.
검은 창이 바로 꺼져요압축을 풀지 않고 zip 안에서 실행했을 가능성이 큽니다. 1번대로 압축을 푼 폴더에서 실행합니다.

알아 두세요

  • 발행은 자동으로 하지 않습니다. 네이버는 자동 프로그램으로 글을 발행하면 계정에 불이익을 줄 수 있어서, 임시저장까지만 하고 발행은 직접 누르도록 만들었습니다.
  • 네이버 비밀번호는 프로그램에 저장되지 않습니다. 브라우저 창에서 직접 로그인하는 방식입니다.
  • API 키, 설정, 말투 예시는 이 PC에만 저장됩니다. 다른 사람에게 줄 때는 "4_다른 사람에게 줄 파일 만들기"로 만든 zip을 보내세요.
  • 새 버전이 나오면 프로그램 화면 맨 위에 노란 알림이 뜹니다. "지금 업데이트"를 누르면 설정은 그대로 두고 프로그램만 바뀝니다. 설정 탭 맨 아래 "새 버전 확인"으로 직접 확인할 수도 있습니다.
  • 익명 사용 통계: 프로그램을 만든 사람이 몇 대의 PC에서 쓰는지 알 수 있게, 하루 한 번 켤 때와 글을 만들 때 무작위 번호, 프로그램 버전, '켬/글 만듦'만 보냅니다. 이름, 블로그 아이디, API 키, 글, 사진은 보내지 않습니다. 원하지 않으면 설정 → ⚙ 고급 설정 → 10. 익명 사용 통계에서 끄면 됩니다.
