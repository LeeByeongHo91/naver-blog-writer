1. 글 형식

    
어떤 글을 쓸지 먼저 고르세요. 형식에 따라 글 구성과 사진 넣는 방식이 달라집니다. 설정에 '내 글 예시'를 넣어 두었으면 말투는 어느 형식이든 그 글을 따라 씁니다.

    

      
      
      
    

  


  

    

      
2. 사진 고르기

      
    

    
글에 넣을 사진을 누르세요. 누른 순서대로 번호가 붙고, 다시 누르면 빠집니다. 순서는 아래 3번에서 바꿀 수 있습니다.
PC에 있는 사진은 이 칸에 끌어다 놓거나 'PC에서 사진 추가'로 넣을 수 있습니다 (사진 폴더에 복사됩니다).

    

      
      
      
      
      
      
      
      
    

    

    

  


  

    
3. 순서와 사진 메모

    
왼쪽 번호를 잡고 끌어서 놓거나 ▲▼ 버튼으로 순서를 바꾸세요. 블로그에 이 순서 그대로 들어갑니다.
메모 칸에 그 사진에서 하고 싶은 말이나 느낌을 적으면 AI가 그 내용을 살려서 씁니다. 비워 둬도 됩니다.

            👤 사용자 
            
    
            이 PC에서 여러 사람(여러 네이버 블로그)이 쓸 때 사용자를 나눠 둡니다. 아래 설정, 네이버 로그인, 이미 쓴 사진 기록, 말투 예시는 사용자마다 따로 저장됩니다. 혼자 쓰면 그대로 두면 됩니다.
            
    
            
      
      
      
      
    
            
    
            사용자는 맨 위 오른쪽 👤 칸에서 바꿉니다.
            
  
            

  
            
    
            1. AI 연결
            
    
            AI가 글을 쓰려면 API 키가 필요합니다. sk-ant-로 시작하는 긴 글자입니다. 받아 둔 키를 붙여넣고 '연결 확인'을 눌러 주세요.
            
    
    
            
      
      
    
            
    
            
    
            
      API 키가 없어요 (처음 한 번만 하면 됩니다)
      
              
        
            1. platform.claude.com 에 접속해서 회원가입합니다. (구글 계정으로 가입하면 쉽습니다)
              2. 
        
            2. Settings → Billing(결제) 메뉴에서 카드 등록 후 크레딧을 충전합니다. 5달러면 글 30편 안팎을 쓸 수 있습니다.
              3. 
        
            3. API Keys 메뉴에서 Create Key를 누르고, 나온 키(sk-ant-로 시작)를 복사해 위 칸에 붙여넣습니다.
              4. 
      
            
      
            자세한 순서는 프로그램 폴더의 0_사용방법 2번에 사진과 함께 있습니다.
            
      
            키는 비밀번호와 같고, 쓴 만큼 키 주인의 카드에서 돈이 나갑니다. 다른 사람에게 보여주거나 보내지 마세요. 이 프로그램을 남에게 줄 때도 키는 같이 가지 않으니, 받은 사람은 자기 키를 만들어 넣어야 합니다.
            
    
            
  
            

  
            
    
            2. 네이버 블로그
            
    
    
            
      
      
    
            
    
            
    
            내 블로그 주소 blog.naver.com/myblog123에서 굵은 부분이 아이디입니다. 블로그 주소를 통째로 붙여넣어도 됩니다. 처음 글을 만들 때 브라우저 창이 뜨면 이 아이디로 직접 로그인하면 됩니다. 글은 임시저장까지만 되고, 발행은 직접 확인한 뒤 누릅니다.
            
  
            

  
            
    
            3. 사진
            
    
            글에 쓸 사진을 모아 둘 폴더를 골라 주세요. 폰 사진을 쓰려면 구글 드라이브 폴더('폴더 고르기' → '구글 드라이브 (내 드라이브)' → 사진 폴더 → '이 폴더 선택')가 편하고, PC에 있는 사진만 쓸 거면 '내 PC 사진 폴더'를 골라도 됩니다.
            
    
    
            
      
      
    
            
    
            
      
            
        
        
      
            
      
              
      
              
        
        
        
      
              
    
              
    
              

    
              
    
    
    

    
              
      
              
        
        
      
              
      
              
        
        
      
              
    
              
    
              
    
              한 번 글에 쓴 사진은 기억해 두고 다음에는 미리 골라 두지 않습니다. 드라이브의 사진은 지우거나 옮기지 않습니다. 사진은 JPG, PNG, WEBP, 아이폰 사진(HEIC)을 읽고, 동영상(MP4, MOV 등)도 넣을 수 있습니다.

              5. 내 글 예시 (말투 따라 쓰기)
              
    
              내가 직접 쓴 블로그 글을 2~3편 넣어 두면, AI가 그 글의 말투, 줄 끊는 길이, 이모지, 인사말을 따라 씁니다. '내 블로그에서 가져오기'를 누르고 마음에 드는 글에 체크하면 끝입니다. 넣어 두면 '말투'와 '글 길이' 설정보다 이 글들이 우선합니다. 한 편 넣을 때마다 글 하나 만드는 데 드는 돈이 조금(약 30~40원) 늘어납니다.
              
    
    
              
      
              
      
                
      
                
        
        
      
                
    
                
    
                
    
                
      
      
      
    
                
    
                나중에 해도 됩니다. 비워 두고 '다 됐어요'를 눌러도 글은 만들어집니다.
                
  
                

  
                
    
    
  
                
  
                

  
                
    ⚙ 고급 설정 (글 맨 위 이미지, 글 끝에 붙일 내용, 네이버 템플릿, 항상 지킬 요청)
  
                
    
                6. 글 맨 위에 항상 넣을 이미지
                
    
                가게·도장 로고, 인사 배너처럼 모든 글의 맨 위(제목 바로 아래)에 똑같이 넣을 이미지입니다. 여러 장이면 이 순서대로 들어갑니다. 넣거나 빼면 바로 저장됩니다.
                
    
                
    
    
    
                ⚠ 네이버는 글의 첫 사진을 대표 이미지(검색 결과에 보이는 썸네일)로 씁니다. 여기에 이미지를 넣으면 모든 글의 대표 이미지가 이 이미지가 됩니다. 글마다 다르게 하고 싶으면 네이버 글쓰기 화면에서 다른 사진에 마우스를 올리고 '대표'를 눌러 바꿔 주세요.
                
  
                
  
                
    
                7. 글 끝에 항상 붙일 내용
                
    
                가게·도장 소개, 네이버 지도, 톡톡, 유튜브, 인스타그램처럼 매번 글 끝(마무리 글과 해시태그 사이)에 똑같이 들어가는 부분입니다. 비워 두면 아무것도 붙이지 않습니다.
                
    
                
      🧩 네이버 '내 템플릿' 쓰기
      
                네이버 글쓰기 화면의 템플릿 → 내 템플릿에 저장해 둔 글 끝(시간표, 배너, 톡톡, 유튜브 등)을 글 맨 아래, 해시태그 바로 앞에 그대로 넣습니다. 템플릿에 이미 있는 링크·지도·문장은 아래 '글 끝 내용'에 적어 두었어도 두 번 넣지 않습니다. 쓰지 않으려면 비워 두세요.
                
      
      
    
                
    

    
                
      📍 네이버 지도 넣기
      
                네이버 지도에 나오는 가게 이름과 도로명 주소를 따로 적고 '지도 줄 만들기'를 누르세요. 같은 이름의 가게가 여러 곳 있어도 주소가 맞는 곳을 넣습니다.
                
      
                
        
                
        
                
      
                
      
    
                

    
    
    
                
      칸에 적는 규칙
      
                  
        
                • 지도: 로 시작하는 줄 → 네이버 지도 장소 카드 (위의 '지도 줄 만들기'가 이 줄을 만들어 줍니다)
                  • 
        
                • 주소(https://...)만 있는 줄 → 링크 카드 (유튜브 채널, 네이버 톡톡, 인스타그램 등). 주소 앞뒤에 다른 글자가 붙으면 카드가 안 됩니다.
                  • 
        
                • // 로 시작하는 줄 → 메모용이라 글에 들어가지 않습니다.
                  • 
        
                • 나머지 줄 → 그대로 글로 들어갑니다. 빈 줄은 문단 사이 여백이 됩니다.

                  9. 쇼츠 목소리·배경 음악
                  
    
                  🗣 AI 목소리
                  
    
                  
      
      
    
                  
    
                  윈도우에 기본으로 들어 있는 한국어 음성으로 읽습니다 (무료, 인터넷 필요 없음). 켜면 AI가 자막을 소리 내 읽기 좋은 한 문장으로 쓰고, 사진은 다 읽을 때까지 보여 줍니다. 배경 음악은 목소리 뒤에 작게 깔립니다.
                  
    
                  🎵 배경 음악
                  
    
                  아래에서 고른 곡(여러 곡이면 영상마다 하나씩)이 쇼츠 영상에 깔립니다. 끝은 서서히 작아집니다. 하나도 안 고르면 음악 없이 만듭니다.
                  
    
                  🎁 무료 기본 음악 (저작권 걱정 없음 · 들어 보고 체크하세요)
                  
    
                  
    
                  HoliznaCC0가 저작권을 포기하고(CC0) 공개한 곡이라 유튜브·인스타그램 어디에 올려도 되고, 출처를 적지 않아도 됩니다.
                  
    
                  📁 내가 넣은 음악
                  
    
                  저작권에 주의하세요. 마음대로 써도 되는 곡만 넣으세요. 가요·드라마 음악을 넣으면 영상이 막히거나 소리가 꺼질 수 있습니다.
                  
    
                  
    
    
  
                  

  
                  
    
                  10. 익명 사용 통계
                  
    
    
                  프로그램을 만든 사람이 몇 대의 PC에서 이 프로그램을 쓰는지 알 수 있게, 하루에 한 번 켤 때와 글을 하나 만들 때 아주 짧은 신호를 보냅니다.
                  
      보내는 것: 이 PC에 처음 만든 무작위 번호, 프로그램 버전, '켬' 또는 '글 만듦'. 이것뿐입니다.
                  
      보내지 않는 것: 이름, 블로그 아이디, API 키, 글 내용, 사진. 끄면 아무것도 보내지 않습니다. (이 PC의 모든 사용자에게 같이 적용, 바로 저장됨)
