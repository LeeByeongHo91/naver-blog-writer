# 블로그 글 생성기

구글 드라이브에 사진을 올려 두면, AI(Claude)가 사진을 보고 내 말투로 글을 써서 **네이버 블로그에 임시저장**까지 해 주는 윈도우 프로그램입니다. 발행은 글을 확인한 뒤 직접 누릅니다.

## 내려받기

👉 **[최신 버전 내려받기 (blog-writer.zip)](https://github.com/LeeByeongHo91/naver-blog-writer/releases/latest/download/blog-writer.zip)**

1. 받은 zip 파일을 바탕 화면에서 **마우스 오른쪽 버튼 → 압축 풀기**
2. 생긴 `블로그글생성기` 폴더의 **`0_사용방법`** 을 열고 순서대로 따라 하기
3. **`1_설치`** 를 더블클릭하면 필요한 것을 알아서 설치하고, 처음 설정 안내가 한 단계씩 나옵니다

## 알아 두세요

- **새 버전이 나오면** 프로그램 화면 위쪽에 알림이 뜹니다. **"지금 업데이트"** 를 누르면 설정은 그대로 두고 프로그램만 바뀝니다. 업데이트 파일은 만든 사람의 서명을 확인한 뒤에만 설치합니다 (1.5.1부터).
- AI를 쓰려면 각자 **자기 API 키**가 필요합니다 (platform.claude.com, 글 하나에 약 100~200원). 키, 설정, 네이버 로그인은 내 PC 안에만 저장되고 이 프로그램을 남에게 줄 때 같이 가지 않습니다.
- 네이버 약관 때문에 **발행은 자동으로 하지 않습니다.** 임시저장까지만 하고 발행은 직접 누릅니다.
- 네이버 비밀번호는 프로그램에 저장되지 않습니다. 브라우저 창에서 직접 로그인합니다.
- 같은 사진으로 **인스타그램용 사진(4:5)·글**과 **유튜브 쇼츠·인스타 릴스용 세로 영상**도 만들어 둡니다. 올리기는 직접 합니다.
- **얼굴 모자이크**를 켜면 사진 속 얼굴을 찾아 가립니다. 얼굴 찾기는 내 PC 안에서만 하고 사진을 어디에도 보내지 않습니다 (OpenCV, [YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) 모델 MIT 라이선스).
- **익명 사용 통계**: 몇 대의 PC에서 쓰는지 알 수 있게 하루 한 번 켤 때와 글을 만들 때 *무작위 번호, 버전, 켬/글 만듦*만 보냅니다. 이름·블로그 아이디·API 키·글·사진은 보내지 않고, **설정 → 고급 설정 → 10번**에서 끌 수 있습니다. 받는 쪽 코드는 [stats-server/Code.gs](stats-server/Code.gs)에 그대로 있습니다.
- 윈도우 10/11, Microsoft Edge에서 동작합니다.
